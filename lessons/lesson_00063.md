## 2. La place de l'adjectif en français

En général, l'adjectif se place après le nom :

- Un livre intéressant.
- Une maison moderne.
- Des étudiants intelligents.

Certains adjectifs se placent avant le nom :

| Adjectif | Exemple |
|---|---|
| beau, joli | un beau paysage |
| jeune, vieux | une jeune femme |
| premier, deux | le premier jour, trois chats |
| bon, mauvais | un bon élève, une mauvaise idée |
| grand, petit | un grand homme, une petite fille |

### Devant une voyelle ou un h muet (masculin)

- beau → **bel** : un bel acteur
- vieux → **vieil** : un vieil homme
- nouveau → **nouvel** : un nouvel ordinateur

Lorsque l'adjectif est placé devant le nom, l'article indéfini pluriel **des** devient **de** (ou **d'** devant une voyelle) :

- J'ai **de beaux livres**.
- Elle a **de grandes idées**.
- Incorrect : ~~J'ai des beaux livres. Elle a des grandes idées.~~
- Après le nom, **des** remains: J'ai **des livres intéressants**.

## 3. Masculin et féminin (suite)

### Terminaisons régulières étudiées

- **-on → -onne** : bon → bonne ; breton → bretonne ; mignon → mignonne
- **-er → -ère** : étranger → étrangère ; boulanger → boulangère ; infirmier → infirmière
- **-eur / -eux → -euse** : serveur → serveuse ; heureux → heureuse
- **-teur → -trice** : acteur → actrice ; éditeur → éditrice ; agriculteur → agricultrice
- Exceptions shown: chanteur → chanteuse ; menteur → menteuse
